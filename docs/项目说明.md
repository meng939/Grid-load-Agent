# 项目说明

## 一句话定位
给定 PJM 电网逐小时负荷序列，AGH 自动完成：数据获取 → 清洗 → 短期负荷预测（T+24h）→ 回测 → 异常事件检测与归因 → 生成带基线对照的验证报告；当数据缺失、传感器跳变或模型不收敛时自动降级并全程记录。

## 问题价值
- 电力负荷预测是电网调度的核心任务；短期（T+24h）预测直接关系发电计划与成本。
- 实际负荷序列常含缺失、传感器跳变、漂移等异常，**自动检测 + 归因**是调度侧真实痛点。
- 本作品用 AGH 把"预测 + 异常"做成一条可复现、可验证的闭环，而非孤立模型。

## 学科融合
环境能源 × 数据科学 × 智能体工程（Agent 闭环）。

## 可验证指标
| 指标 | 来源 | 对照 |
|---|---|---|
| MAE / RMSE / MAPE | 滑窗回测 | 朴素"昨日同期"基线 |
| 异常事件召回 | 注入异常 + 检测 | 注入位置为真值 |
| 插补率 | 缺失注入 | 注入率对照 |
| 模型回退 | 截断样本 | 是否触发换模型 |

## 异常处理闭环（核心得分点）
| 异常类型 | 注入方式 | AGH 行为 | 验证证据 |
|---|---|---|---|
| 数据缺失 | 随机置空 5% | clean_df 标记+插补，记录插补率 | 插补前后对比 |
| 传感器跳变 | 注入 10 个 5σ 尖峰 | detect_anomaly 捕获+归因"瞬时尖峰" | 事件列表+位置图 |
| 模型不收敛 | 截断训练样本 | train_predictor 降采样+换模型 | 回退日志 |
| 回测不达标 | 阈值未过 | verify_report 标红+触发重训 | 基线对照表 |
| 接口超时 | 模拟网络抖动 | fetch_data 重试3次+降级本地缓存 | 重试日志 |

演示时主动触发至少 2 类异常，证明 AGH 真实读反馈、走分支。

## 复现
```bash
pip install -e .
python tools/make_synthetic.py   # 无真实 PJM 数据时生成仿真缓存
python run.py --demo
```
