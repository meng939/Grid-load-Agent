# 模型合规声明

## 声明
1. 本作品所有 **LLM 推理调用仅限 Agnes 模型**（由 Agnes Harness 内置提供），
   未接入、未调用任何其他厂商、品牌或第三方大模型推理接口。

2. 数值计算与经典机器学习使用本地开源库：
   - `lightgbm`（主预测器）
   - `scikit-learn`（HistGradientBoosting 降级模型、孤立森林可选）
   - `pandas` / `numpy`（数据与特征）
   上述为本地开源数值库，**不涉及任何第三方 LLM 推理**。

3. 数据来自 PJM 公开负荷数据（或经 `tools/make_synthetic.py` 生成的仿真序列
   用于链路验证），未使用任何非公开专有数据。

4. 本作品未使用任何真实硬件或远程设备，验证在本地仿真/公开数据上完成，
   符合"无硬件条件可使用仿真、数字孪生或公开数据完成项目验证"之规定。

## 口径说明
"模型调用仅限 Agnes 模型"在本作品中解释为：**LLM 层仅 Agnes**；
数值/经典 ML 层使用本地开源库，属赛题允许的"本地库"范畴，非第三方模型调用。
