# 下一步操作清单（在你自己电脑上执行）

## 1. 安装依赖（一次性）
```powershell
cd project
python -m pip install -e .
```
> 依赖已验证可装：pandas / numpy / scikit-learn / lightgbm / statsmodels / matplotlib。
> 若 lightgbm 因 Python 3.14 缺 wheel 装不上，跳过它——代码有三级降级
> （LightGBM → HistGradientBoosting → 纯 numpy Ridge），跑通闭环靠后两级即可。

## 2. 接入 ERCOT 真实负荷数据（二选一）

**A. 手动下载（免注册，推荐先用）**
```powershell
# 1) 浏览器打开 https://www.ercot.com/marketinfo/loads
# 2) 选至少 1 年范围 → Download CSV
# 3) 把文件复制为 project/data/ercot_load_raw.csv
# 4) 转换并写入缓存：
python tools\fetch_ercot.py --local data\ercot_load_raw.csv
```

**B. 自动下载（需注册 ERCOT API key）**
```powershell
# 注册：https://api.ercot.com  → 生成 API Key
python tools\fetch_ercot.py --api-key 你的KEY --start 2024-01-01 --end 2024-12-31
```

两种路径都产出 `data/pjm_load_cache.csv`（timestamp, load_mw 两列），
之后 `fetch_data` 自动读到真实数据。

> 仓库里已有一份测试用的 `data/ercot_load_raw.csv`（仿真 ERCOT 格式，8760 小时），
> 可先 `python tools\fetch_ercot.py --local data\ercot_load_raw.csv` 体验全链路，
> 之后再换成真实下载的文件覆盖。

## 3. 跑通闭环（自适应阈值已内置）
```powershell
python run.py --demo             # 主路径 + 注入 missing/spikes + 出报告
python run.py --baseline-only    # 仅基线对照
python run.py --anomaly threshold # 触发"回测不达标→重训"分支
```
**判定逻辑（已自洽）**：
- 不注入异常 → 判定「通过」（正常工况）
- 注入 threshold / 真实异常 → 判定「未通过」（MAE 超过自适应通过线）
- 通过线 = 1.25 × 未注入工况的 MAE（`backtest` 自动标定，日志 `[calibrate]` 行可查）

产物：
- `reports/report_*.html`  验证报告（指标对照 + 异常事件 + 运行日志）
- `validation/metrics.csv` 模型 vs 基线指标
- `validation/anomaly_events.csv` 异常事件清单（含归因）
- `runs/run_log.txt` 全程日志
